# Personas

## Command Center Operator
Responsibilities:
- Monitor incidents
- Dispatch resources
- Evaluate coverage impact
- Coordinate multi-agency response

## First Responder
Responsibilities:
- Receive assignments
- Navigate to incidents
- Track ETA and route changes

## AI Copilot User
Questions:
- Which EMS unit can arrive fastest?
- What hospitals are reachable within 15 minutes?
- Summarize current operations.
